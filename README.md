# Видео из Telegram → каталог инструментов дизайнера на Miro

Кидаешь боту ссылку на reels с подборкой инструментов — через несколько минут на доске появляется карточка на каждый инструмент: назначение, где взять, ссылка и кадр из ролика, по которому видно, где ты это увидел.

## Здесь только конфиг

Кода в этом репозитории нет. Движок живёт в [NikolajKava/miro-tools-bot](https://github.com/NikolajKava/miro-tools-bot) и подтягивается воркфлоу при каждом запуске — по тегу, а не по `main`, чтобы правки в движке не приезжали сюда сами собой.

| Файл | Роль |
|---|---|
| `profile.json` | предмет каталога и категории с цветами |
| `.github/workflows/process.yml` | два checkout: движок по тегу + этот профиль |
| `.github/workflows/keepalive.yml` | чтобы GitHub не усыпил cron |

Версия движка задаётся переменной `ENGINE_REF` в начале `process.yml`. Обновиться до новой — поменять там тег.

## Настройка

**Secrets:**

| Имя | Что это |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен своего бота от @BotFather |
| `CLAUDE_CODE_OAUTH_TOKEN` | вывод `claude setup-token` |
| `MIRO_TOKEN` | access token приложения Miro |

**Variables:**

| Имя | Что это |
|---|---|
| `MIRO_BOARD_URL` | адрес доски каталога |
| `TELEGRAM_ALLOWED_CHATS` | chat_id тех, кого бот слушает |

Подробности по каждому токену — в README движка.

## Свои категории

Правятся в `profile.json`: `subject` определяет, что вообще считать инструментом, `categories` задаёт список и цвета карточек. Категория вне списка получит серый цвет.
